# Multi-Stage Attack: Credential Theft & Evasion

### Description
This **Advanced Correlation** rule triggers a critical alert only if a specific temporal "Kill Chain" is completed. The attacker performs three actions on the same machine within a maximum of 60 minutes: 
1. Disables Windows Defender protections.
2. Launches an obfuscated PowerShell payload.
3. Dumps the memory of the LSASS process to steal credentials.

## MITRE ATT&CK
* **Tactic:** Defense Evasion (TA0005), Execution (TA0002), Credential Access (TA0006)
* **Technique:** Impair Defenses (T1562.001), Obfuscated Files or Information (T1027), OS Credential Dumping: LSASS Memory (T1003.001)

## Alert Metadata
* **Severity:** CRITICAL
* **Confidence:** High (Such a sequence generated by a legitimate user/admin is extremely rare and violates all security policies)
* **Impact:** Critical

### SPL Query (Correlation Engine)
```splunk
(index=wineventlog OR index=sysmon) 
( 
  (EventCode=1 OR EventCode=4688) ("* -enc *" OR "* -encodedcommand *") 
) OR ( 
  ("*DisableRealtimeMonitoring*" OR "*Set-MpPreference*") 
) OR ( 
  EventCode=10 TargetImage="*\\lsass.exe" 
)
| transaction host maxspan=60m
| search "lsass.exe" AND ("-enc" OR "-encodedcommand") AND ("DisableRealtimeMonitoring" OR "Set-MpPreference")
| eval Attack_Chain="CRITICAL ALERT: Encoded Powershell Execution -> Defender Disabling -> LSASS Access and Dumping"
| table _time, host, duration, Attack_Chain
```

### Triage & Recommended Actions
Since this is a complex, high-fidelity attack chain, if this alert triggers, you are dealing with an active security incident (Incident Response) in progress.

1. **Isolate immediately** the infected host from the network to prevent lateral movements.
2. **Credential reset:** Since there was access to LSASS, force a password reset for all users who had an active session on that host.
3. **Payload Analysis:** Extract the alert timeline query and decode the Base64 string to understand which C2 server the attacker was contacting.
