# Multi-Stage Attack: Possible Domain Compromise

### Description
This is an **Advanced Correlation** rule. It does not look for a single event, but tracks a specific "Kill Chain". The alert triggers only if, on the same machine, an attacker creates a fake user (4720), promotes them to Administrator (4732), and subsequently clears the security logs to cover their tracks (1102).

## MITRE ATT&CK
* **Tactic:** Persistence, Privilege Escalation, Defense Evasion
* **Technique:** Account Manipulation (T1098), Indicator Removal on Host (T1070)

## Alert Metadata
* **Severity:** CRITICAL
* **Confidence:** High (Such a sequence generated by a legitimate user is extremely rare and violates security policies)
* **Impact:** Critical

### SPL Query (Correlation Engine)
```splunk
(index=wineventlog OR index=sysmon) 
(
  EventCode=4720
) OR (
  EventCode=4732
) OR ( 
  EventCode=1102
)
| transaction host maxspan=30m
| search EventCode=4720 AND (EventCode=4732 AND Group_Name=Administrators) AND EventCode=1102
| eval Attack_Chain="CRITICAL ALERT: Local Account Creation -> Account added to Administrators -> Log Clearing"
| table _time, host, duration, Attack_Chain
```
## Triage & Recommended Actions
Since this is a high-fidelity correlation rule, if this alert triggers, the host is almost certainly compromised.

1. Isolate the host from the corporate network immediately.

2. Check previous logs to understand which initial access vector was used (for example, RDP, phishing, exploit).
